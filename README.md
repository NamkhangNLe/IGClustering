# IGClustering — Instagram ego-network analysis

How separated is everyone in one person's Instagram network? This project
answers that with real data: a snapshot of Namkhang's followers and
following from April 2024, turned into a graph, analyzed, and visualized.

**Open `index.html` in a browser** for the interactive version: a radial
ego network with all 789 people, search, and group filters.

## Findings

| | |
|---|---|
| Followers | 615 |
| Following | 571 |
| Mutuals | 397 |
| Followers only | 218 |
| Following only | 174 |
| Unique people | 789 |

- **Everyone is 1 hop from Namkhang and 2 hops from everyone else.** The
  data is 1-hop only, so the graph is a star: 790 nodes, 789 edges,
  diameter **2**, average shortest path **1.9975**, clustering
  coefficient **0**. Any two people in this network connect through
  exactly one intermediate.
- **69.5% of the accounts Namkhang follows follow him back** (397 of
  571). **64.6% of his followers are people he follows back** (397 of
  615).
- The non-mutuals split unevenly: 218 people follow him without a
  follow-back, versus 174 accounts he follows that don't follow him.
  The following-only side is mostly brands, meme pages, and GT accounts.

## What this does not answer

The original question, Ivy League vs Georgia Tech separation, **cannot be
answered from this dataset**. The scrape collected username and full name
only. There is no school affiliation anywhere in the data, and no
second-hop edges (we never collected who anyone else follows). To answer
it for real you would need, per person, a school label and at least one
more hop of follow edges. Instagram no longer exposes that data through
the endpoints this scraper used, so the honest finish is the ego-network
analysis above, not an invented school clustering.

## How to run

```bash
pip install -r requirements.txt

# Reproduce every number + the static plot (MVP/results.json, MVP/ego_network.png)
python3 MVP/analyze.py

# Re-render just the static plot
python3 MVP/graphing.py

# Regenerate the interactive page (index.html) from the data
python3 make_index.py
```

## Project structure

| File | What it does |
|---|---|
| `index.html` | Interactive visualization (self-contained, no build step, no CDN). Generated by `make_index.py`. |
| `make_index.py` | Builds `index.html` from the MVP data. |
| `MVP/scrape.js` | Browser-console scraper that dumped the follower / following JSON (April 2024, Instagram's old GraphQL endpoints, now defunct). |
| `MVP/merge.py` | Joins followers + following into `Merged.csv` (the 397 mutuals). Verified to reproduce the committed CSV exactly. |
| `MVP/analyze.py` | Validates the derived lists, computes the graph statistics, writes `results.json`, renders `ego_network.png`. |
| `MVP/graphing.py` | Re-renders the static ego-network plot. |
| `MVP/results.json` | The computed statistics. |
| `MVP/*.json` | The snapshot: followers, following, and the two derived lists. |

## Data

Snapshot: April 2024. Usernames in this repo are already public in the
MVP data files. 36 followers and 23 following have no full name recorded.
